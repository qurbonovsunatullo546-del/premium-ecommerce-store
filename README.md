# Premium E-Commerce Store

Full-stack интернет-магазин с каталогом товаров, корзиной и управлением заказами, разработанный на **Java Spring Boot** и **React (TypeScript)**.

## Стек технологий
* **Backend:** Java, Spring Boot, Maven
* **Frontend:** React, TypeScript, Vite, Tailwind CSS

## Структура проекта
```text
├── backend/    # REST API и бизнес-логика (Spring Boot)
└── frontend/   # Клиентская часть (React + TypeScript + Tailwind CSS)
